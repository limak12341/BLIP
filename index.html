📖 Jak działa Provably Fair?
1 Serwer generuje Server Seed — pokazuje tylko jego hash (SHA-256), nigdy samego seeda.
2 Ty ustawiasz swój Client Seed — możesz go zmienić przed grą.
3 Wynik gry = HMAC-SHA256(ServerSeed, ClientSeed + Nonce). Nonce rośnie po każdej grze.
4 Po grze serwer ujawnia Server Seed. Możesz zweryfikować, że hash się zgadza, a wynik został wygenerowany uczciwie.
